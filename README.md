# Programmer7-dev.github.io

Host-level redirect and favicon for the Crafted Resistance site.

- Game site: https://programmer7-dev.github.io/CraftedResistance/
- Main repository: https://github.com/Programmer7-dev/CraftedResistance

The root page redirects to the project site and provides `/favicon.ico` at the host root, which some search crawlers check. The root `robots.txt` allows crawling and points to the project sitemap.
